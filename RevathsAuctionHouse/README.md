# Obsolete Auction House module

This module is retired. Its Lua source and regression tests remain in the repository for reference, but its manifest loads no runtime files. It is excluded from suite builds, releases, and settings.

Do not install this folder. When upgrading from an older release, disable or remove the existing `RevathsAuctionHouse` folder from `Interface/AddOns`; extracting the new suite ZIP does not remove old addon folders.
