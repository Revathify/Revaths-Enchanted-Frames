# v5.1.0

- Renamed Native WoW HUD to Classic, with existing Whispers settings migrated automatically.
- Classic now uses consistent native WoW borders, dark panels and buttons across Mailbox, Macros, Weekly Planner and Whispers.
- Mailbox Classic keeps the compact header and normal content layout, with readable mail text instead of the old parchment treatment.
- Incoming whispers open Enchanted Whispers by default without taking keyboard focus or switching an already-open conversation.
- Starting a whisper through Blizzard chat, /w, /whisper, Reply or Battle.net hands the recipient and typed draft to Enchanted Whispers.
- Blizzard-restricted chat remains with Blizzard's input; drafts are never sent automatically.
