Enchanted Whispers joins the suite: a compact native WoW window with a narrow conversation list, character and Battle.net whispers, unread counts, saved drafts, bounded message history, and a matching transparent minimap icon.

Choose a native, Modern, or Classic-inspired appearance, adjust message fonts and opacity, and select Blizzard, shared-media, or custom-file notification sounds. Resize the window independently of text size.

Whisper handling avoids combat popup/focus changes and preserves drafts when Blizzard restricts addon chat access.

Mailbox, Macros, and Weekly Planner gain an optional native WoW window border in their shared appearance settings.

Validation, packaging, and release publishing now run in the local Jenkins project instead of GitHub Actions.
